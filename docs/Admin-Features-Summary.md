# Feedee Forums — Admin features summary

Quick reference generated with the Admin Panel User Guide (November 2026).

## Documented working features

1. **Admin authentication** — role-gated access to `/admin`, login, logout, intended redirect  
2. **Dashboard** — pending posts, unread contacts, approvals today, member counts, 7-day chart, pending queue preview, latest messages, support overview  
3. **Posts moderation** — tabs, search/topic filter, approve / reject / feature / delete, bulk actions, require-approval switch  
4. **Customers** — list, activity tabs, search, post counts, view posts, mailto  
5. **Contact messages** — unread/read tabs, search/subject filter, detail view, mark unread, mailto reply, delete  
6. **Settings — Support button** — enable/disable, YouPay / Cash App URLs and captions  
7. **Settings — Email** — log or SMTP, from identity, contact recipient, test email  
8. **Support link analytics** — period filters, platform totals, countries, activity, CSV exports  
9. **30-day post cleanup** — lifetime policy + scheduler dependency  
10. **In-app docs** — `/admin/docs` HTML guide  

## Not documented as production-ready

1. **`/admin/reports`** — static mock UI only  
2. **Customer edit / ban / delete** — not implemented  
3. **Role management UI** — not implemented  
4. **In-panel contact reply composer** — mailto only  
5. **Sidebar entry for `/admin/docs`** — missing from navigation
